도움말

1. 이 도구는 무엇인가요?

공공기관이 정보화사업을 발주할 때 필요한 "제안요청서(RFP)" 초안을 자동으로 만들어주는 도구입니다. 정보화사업 실무 경험이 없어도, 몇 가지 질문에 답하기만 하면 표준 형식에 맞는 문서 초안이 생성됩니다.

2. 사용 순서

  1. 사업 유형 선택 — 왼쪽에서 추진하려는 사업과 가장 비슷한 유형을 고릅니다.
  2. 사업명 입력 — 사업명을 적으면 자동으로 비슷한 과거 사업(주로 통일부 발주)을 찾아 보여줍니다. 참고할 만하면 선택하고, 아니면 그냥 넘어가도 됩니다.
  3. 나머지 정보 입력 — 아는 만큼만 채웁니다. 모르는 항목은 비워두세요.
  4. 초안 생성 — 버튼을 누르면 워드(.docx) 파일로 초안이 만들어져 다운로드됩니다. 국가법령정보센터에서 받아온 실제 공식 서식(하도급 계획서 등)은 원본과 동일한 표 구조로 초안 안에 그대로 포함됩니다.

3. 모르는 항목은 어떻게 되나요?

절대 그럴듯하게 지어내지 않습니다. 대신 "[◯◯을 입력하세요]" 같은 빈 템플릿으로 남겨두고, 배점표·입찰참가자격·하도급 규정처럼 국가 공통으로 정해진 부분만 표준 내용으로 자동으로 채웁니다. 즉, 이 초안은 100% 완성본이 아니라 담당자가 이어서 채우고 검토해야 하는 출발점입니다.

4. 공공데이터포털 인증키가 뭔가요?

조달청이 운영하는 나라장터의 공고 정보를 실시간으로 가져오기 위한 열쇠 같은 것입니다. 없어도 예시 데이터로 도구를 체험할 수 있고, 관리자가 기관 공용 키를 설정해뒀다면 신경 쓰지 않아도 자동으로 실제 데이터가 조회됩니다.
