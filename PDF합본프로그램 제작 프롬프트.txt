
아래와 같이 PDF 합본 프로그램 만들어줘

## 목적
여러 개의 PDF 파일을 사용자가 지정한 순서대로 하나의 PDF 파일로 합쳐주는 프로그램을 만들어줘.
## 형태
- 설치나 서버 없이 브라우저에서 바로 열어서 쓸 수 있는 단일 HTML 파일로 제작 (예: pdf-lib.js CDN 사용)
- 인터넷이 안 되는 환경도 고려해서, 가능하면 필요한 라이브러리를 파일 내에 포함하거나 오프라인 사용법을 안내
- 한글 UI로 제작
## 핵심 기능
1. 여러 PDF 파일을 한 번에 선택/드래그앤드롭으로 업로드
2. 업로드된 파일 목록을 카드/리스트 형태로 표시 (파일명, 페이지 수, 용량)
3. 드래그앤드롭으로 파일 순서 변경 가능
4. 목록에서 개별 파일 삭제 가능
5. "합본하기" 버튼 클릭 시 지정한 순서대로 PDF 병합
6. 병합된 결과 파일을 다운로드 (파일명은 직접 지정하거나 기본값 예: "합본_20260807.pdf")
## 추가로 있으면 좋은 기능 (선택)
- 파일별 특정 페이지 범위만 선택해서 합치기 (예: 1-3페이지만)
- 병합 전 각 PDF 첫 페이지 썸네일 미리보기
- 파일 개수/총 페이지 수 표시
- 잘못된 파일(비-PDF, 손상된 파일) 업로드 시 에러 안내
- 병합 진행 상태 표시(프로그레스 바) — 대용량 파일 대비
## 제약 조건
- 모든 처리는 클라이언트(브라우저) 단에서만 이루어져야 함 (서버 업로드 없음 — 개인정보/문서 보안 때문에 중요)
- 파일 용량이 큰 경우(수십 MB)에도 브라우저가 멈추지 않도록 처리
- 크롬, 엣지 등 최신 브라우저에서 정상 동작
## 디자인
- 깔끔하고 직관적인 UI (드래그앤드롭 영역 명확히 표시)
- 모바일보다는 데스크톱 사용 기준으로 최적화
