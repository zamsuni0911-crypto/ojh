1. Anthropic API 키

키는 이 컴퓨터의 브라우저에만 저장되며, 로컬 프로그램을 거쳐 Anthropic API로 직접 전송됩니다. (다른 사람이나 개발자에게 전달되지 않습니다)

API 키가 없으신가요? (발급 방법 보기)
  1. console.anthropic.com 접속 후 로그인/회원가입
  2. 왼쪽 메뉴 API Keys → Create Key 클릭
  3. Billing 메뉴에서 결제수단 등록 (사용한 만큼만 과금)
  4. 생성된 sk-ant-... 키를 복사해서 위 입력칸에 붙여넣기
