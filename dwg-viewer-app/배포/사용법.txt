========================================================================
  DWG · DXF 도면 뷰어  (캐드 프로그램 불필요 / 인터넷 불필요)
========================================================================

■ 무엇인가요?
  AutoCAD 도면 파일(.dwg / .dxf / .dwt)을 AutoCAD 등 캐드 프로그램 없이
  웹브라우저만으로 열어 보는 뷰어입니다. 파일은 PC 밖으로 전송되지 않으며
  (모든 처리는 브라우저 안에서 실행), 인터넷이 없어도 동작합니다.

  지원: DWG/DXF R12 ~ 최신(2018/2019/2020) 형식, 블록·해치·치수·문자 포함
  기능: 확대/축소, 이동, 레이어 켜기/끄기, 도면 정보, PDF/SVG 내보내기


  ※※ 중요 ※※
  HTML 파일을 그냥 "더블클릭"해서 열면 브라우저 보안정책상 DWG 를 열 수
  없습니다("불러오기 실패" 표시). 반드시 아래 [방법 1] 또는 [방법 2] 로
  실행하세요. (DXF 는 더블클릭으로도 대체로 열립니다.)


■ 여는 방법

  [방법 1] 회사 인트라넷/파일서버에 올려서 쓰기  ← 가장 권장
    DWG_뷰어_단일파일.html 파일 하나만 웹서버에 올리면 됩니다.
    직원은 그 주소(http://...)를 브라우저 즐겨찾기에 넣고 사용합니다.
    설치·업데이트가 중앙에서 한 번에 끝납니다.

  [방법 2] 각자 PC 에서 런처로 실행 (설치 불필요)
    아래 3개 파일을 반드시 "같은 폴더"에 둡니다.
        - DWG_뷰어_단일파일.html
        - 도면뷰어_열기.bat
        - viewer-server.ps1
    "도면뷰어_열기.bat" 을 더블클릭 → 기본 브라우저에 뷰어가 열립니다.
    (검은 창이 하나 뜹니다. 다 쓰면 그 창을 닫으면 종료됩니다.)
    ※ Windows 10/11 기본 기능만 사용합니다. 관리자 권한 불필요.
    ※ 처음 실행 시 "Windows의 PC 보호" 창이 뜨면
       [추가 정보] → [실행] 을 누르세요.
    ※ 회사 보안정책으로 .bat 실행이 막히면 [방법 1] 을 사용하세요.

  [방법 3] HTML 을 그대로 더블클릭  (DXF 전용, DWG 불가)
    화면은 열리지만 DWG 는 "불러오기 실패" 가 납니다.
    DXF 만 볼 때 임시로 쓸 수 있습니다.


■ 쓰는 법
  1) 뷰어 화면에서 도면 파일을 끌어다 놓거나 "찾아보기" 로 선택
  2) 잠시 변환 후 도면이 표시됩니다 (큰 도면은 10~30초 걸릴 수 있음)
  3) 마우스 휠 = 확대/축소, 드래그 = 이동, 우측 툴바 = 레이어/뷰 도구
  4) 다른 파일을 열려면 좌측 상단 "열기" 버튼


■ 브라우저
  Microsoft Edge 또는 Chrome 최신 버전 권장. (Internet Explorer 불가)


■ 폰트 안내
  자주 쓰는 서구권 SHX + 한글 SHX(whgtxt, whtgtxt 등)는 파일에 내장되어
  오프라인에서도 표시됩니다. 그 밖의 특수 SHX/중국어 대용량 폰트가 쓰인
  도면은 해당 글자가 기본 폰트로 대체 표시될 수 있습니다(도형은 정상).
